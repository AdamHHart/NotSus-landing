Download for Android

Version 2.2.0 · 9 MB · Android 7 and newer

How to Install

  1. Tap Download above, on the tablet itself. When your browser asks, choose Download anyway.
  2. Open the file from the download notification.
  3. Android will say it cannot install from this source. Tap Settings, turn on Allow from this source, then press back. Samsung calls this switch Install unknown apps.
  4. Play Protect will say Unsafe app blocked. Tap More details, then Install anyway.
  5. Tap Install, then Open.
